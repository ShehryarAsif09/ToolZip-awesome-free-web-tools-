## Contributing

Additions welcome! Please:

1. Check the tool is actually free and requires no signup
2. Verify the tool is functional (not abandoned)
3. Add it to the correct category
4. Keep descriptions concise (under 10 words)
5. Submit a PR with the format: `| [Tool Name](URL) | Description |`

Tools that require accounts, have heavy ad walls, or are paid-first will not be listed.
